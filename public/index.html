Report Limitations — Read Before Acting

Not a Carfax replacement

This report uses publicly available government data only (NHTSA). It is a starting point for research — not a complete vehicle history.

Accident history not available — NHTSA does not track per-VIN crash records
Title brands not shown — salvage, rebuilt, flood & lemon law require a paid report
Insurance claims not shown — total-loss records are not in public data
Odometer fraud undetectable — only a paid history report can flag mileage rollback
Missing data shows "Not Available" — nothing is fabricated
Official sources only — NHTSA, licensed APIs, no scraping
Always get a professional mechanic inspection and a paid vehicle history report (Carfax, AutoCheck) before purchasing any used vehicle.
